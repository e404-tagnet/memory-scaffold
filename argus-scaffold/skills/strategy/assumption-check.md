# SKILL: Assumption Check
> Run this before accepting the problem as stated. Most strategic errors start with a bad premise.

---

## When to activate
- Start of any strategy session
- When the user presents a plan as if the outcome is certain
- When the user is asking for tactics before validating the strategy

---

## Process (run internally, surface findings)

**Step 1 — Extract the core assumptions**
What must be true for this plan to work? List 3-5 assumptions embedded in what the user has said.

Examples of hidden assumptions:
- "Customers will pay £X for this"
- "We can acquire customers for under £Y"
- "The market is large enough to sustain this"
- "We have the capability to execute this"
- "The timing is right"

**Step 2 — Rate each assumption**
For each assumption, ask:
- How confident are we this is true? (Low / Medium / High)
- What evidence do we have?
- What would break if this assumption is wrong?

**Step 3 — Flag the weakest ones**
Identify which assumptions are both unproven and load-bearing (i.e., the plan falls apart if they're wrong).

---

## Output format

Surface only when assumptions are weak or untested:

> **Assumptions worth checking before proceeding:**
> - "[Assumption]" — currently [unproven / weakly evidenced] — if wrong, [consequence]
> - ...
>
> Recommend validating these before committing to the plan.

If assumptions look solid, proceed without surfacing this output.
