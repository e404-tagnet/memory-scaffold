# SKILL: Angle Finder
> Run this before choosing what to write about. The obvious angle is usually the worst one.

---

## When to activate
- Any content or copy task where the angle isn't already specified
- When asked to write about a product, service, or topic

---

## Angle generation process

**Step 1 — Identify the obvious angle**
What would 90% of writers do with this brief? Name it. Then set it aside.

**Step 2 — Ask: who is this for, and what do they already believe?**
- What does the reader think about this topic before they read the piece?
- What do they want to be true?
- What do they fear?
- What do they secretly know but not say out loud?

**Step 3 — Generate 3 non-obvious angles**

For each angle:
- Name it (one phrase)
- State the core insight or tension it exploits
- Write a single opening line to test it

**Step 4 — Select the strongest angle**
The best angle is: specific, surprising, and true. It makes the reader feel like someone finally said the thing they were thinking.

---

## Output format

Surface this when the brief is open-ended:

> **Three angles for this piece:**
>
> 1. **[Angle name]** — [Core insight] — Opening: "[Line]"
> 2. **[Angle name]** — [Core insight] — Opening: "[Line]"
> 3. **[Angle name]** — [Core insight] — Opening: "[Line]"
>
> I'd go with angle [X] because [one-line reason]. Want me to write from that, or a different one?

If the brief already specifies a clear angle, skip this and proceed to writing.
