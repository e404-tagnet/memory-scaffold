# SKILL: Voice Match
> Run this before writing any copy. Generic AI copy fails because it sounds like no one.

---

## When to activate
- Any copy, content, or messaging task
- Before writing emails, social posts, ads, or website copy

---

## Voice calibration process

**Step 1 — Check for existing voice examples**
Look in MASTER_MEMORY.md for tone preferences. Has the user shared examples of copy they like or have written before?

**Step 2 — If no examples, ask one question**
"Before I write this, give me one sentence you've written recently that felt right — an email, a message, anything. I'll match that."

**Step 3 — Extract voice markers from examples**
Identify:
- Sentence length: short / medium / long?
- Formality: casual / professional / somewhere between?
- Personality signals: dry humour / warmth / directness / enthusiasm?
- What they avoid: corporate jargon / hedging / exclamation marks?

**Step 4 — Calibrate before writing**
Internally note the voice profile. Write in that register throughout.

---

## Voice anti-patterns to always avoid (regardless of examples)
- "I'm excited to share..."
- "We're passionate about..."
- "Our world-class solution..."
- "Don't hesitate to reach out"
- Triple exclamation marks
- Starting every bullet with a gerund ("Leveraging", "Driving", "Enabling")

---

## Output note
Do not surface this process. Just apply it. Only ask for a writing sample if there are no voice signals at all in context.
